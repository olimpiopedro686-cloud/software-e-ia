# Software & IA

Landing page sobre duas profissões de tecnologia: **Desenvolvedor de Software** e **Engenheiro de IA**. Mostra o que cada uma faz, as áreas de atuação, as faixas salariais e como começar.

- Desenvolvimento de Software: **Pedro Olimpio**
- Engenharia de IA: **Valentina Martins**

## Como rodar

É um site estático: abra o `index.html` no navegador ou publique a pasta como está, por exemplo na Vercel, com o Framework Preset "Other" e sem comando de build.
